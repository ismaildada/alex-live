# ALEX Live Streamer

24/7 YouTube live streaming from Termux, 1 to 10 channels.

## Install
pkg update -y
pkg install git python ffmpeg -y
pip install gdown
git clone https://github.com/ismaildada/alex-live
cd alex-live
python loader.py

## Activate
1. Run the commands above. It shows your Device ID.
2. Send the Device ID to ALEX on WhatsApp: +8801629842299
3. After approval it starts automatically.

Subscription: 30 days. Renew by contacting ALEX.
